# Face Recognition using LBPH + OpenCV

Classical face recognition system (no deep learning) using MediaPipe's face detector + LBPH recognizer.

## How to Run

1. `python capture_faces.py` → do this for at least 2 people
2. `python train_model.py`
3. `python recognize_live.py` → record your demo video here!
